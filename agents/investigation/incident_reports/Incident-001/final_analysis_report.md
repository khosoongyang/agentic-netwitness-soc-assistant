# INVESTIGATION SUMMARY: INC-52825 (Incident-001)

**Final Severity:** High
*Rated High because the incident shows a likely compromise on a non-critical asset with SYSTEM-context execution, suspicious service and registry manipulation, internal host-to-host movement indicators, and outbound HTTPS to an external IP. This aligns with Appendix A High severity and includes escalation factors such as privileged-context activity, repeated suspicious process activity, and potential lateral movement. However, the evidence is still incomplete for full process lineage, confirmed privilege escalation chain, and confirmed exfiltration, so the conclusion is strong but not fully closed under Appendix F.*

## Recommended Containment Actions
- Immediately isolate host BETHANYCHUCHU from the network through EDR network containment, preserving management-plane access only if required for forensic acquisition.
- Quarantine or suspend vmtoolsd.exe and any child processes spawned from the suspicious execution chain, then block execution of the observed hash 8f490791f7164633e2bc3bfe129c829986a45b918566c2fe1d63f3c77b0eb28c across all endpoints.
- Collect volatile evidence from BETHANYCHUCHU before reboot: full process tree, active network connections, loaded modules, scheduled tasks, services, autoruns, and memory image.
- Preserve and export the exact command lines and scripts observed in the alert bundle, including resume-vm-default.bat, suspend-vm-default.bat, the reg.exe EnableLUA modification, and the wevtutil manifest operations, for forensic review.
- Block outbound connectivity to 4.145.79.81 and any other resolved infrastructure associated with the incident until scoping is complete, and monitor for alternate egress paths.
- Hunt across the enterprise for the same vmtoolsd.exe hash, the same command-line patterns, and the same registry change to EnableLUA=0 on other Windows endpoints.
- Review Security and Sysmon telemetry on BETHANYCHUCHU for Event IDs 4688, 4624, 4672, 4697, 7045, 1, 3, 11, and registry auditing related to policy changes and service manipulation.
- Validate whether internal host-to-host activity involving 192.168.10.202, 192.168.10.204, 192.168.10.205, 192.168.10.207, 192.168.20.16, and 192.168.20.201 represents additional compromised systems and isolate any host showing the same execution pattern.
