**Final Severity:** High
*High is appropriate because the incident shows suspicious SYSTEM-context execution on an endpoint, service and registry manipulation, and outbound HTTPS to a listed external IP. - Immediately isolate BETHANYCHUCHU from the network using EDR host containment or switch port quarantine, preserving a path for IR remote access if required.

- Collect full Windows Security and Sysmon telemetry for the window 2025-07-14 10:30:00Z through 2025-07-14 11:30:00Z, focusing on Event IDs 4688, 4624, 4672, 4697, 7045, 5140, and 5156, plus Sysmon 1, 3, 6, 7, 11, and 13.

- Block outbound connections to 4.145.79.81 at perimeter and host firewall layers, and hunt for any repeat connections from BETHANYCHUCHU to the same IP or related Microsoft-hosted infrastructure observed in the telemetry.
- Review and revert any registry changes under HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System, especially EnableLUA=0, and validate whether any other hardening or UAC-related keys were altered.
- Search for unauthorized local accounts and group membership changes, especially admin2 and any recent additions to the local Administrators group, then disable and remove any unauthorized accounts after evidence capture.
